# WillBio Personal Website

This is a modern React-based personal website built with Vite. It includes sections for bio, services, resume, portfolio, and contact so prospective clients can quickly understand your web development offerings.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repo to GitHub (or another Git provider supported by Vercel).
2. Create a new project in Vercel and import the repository.
3. Use the following settings:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Click **Deploy**.

You can also deploy from the CLI:

```bash
npm install -g vercel
vercel
```
